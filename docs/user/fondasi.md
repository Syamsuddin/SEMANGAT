# Panduan singkat — Fondasi (M01)

- **ASN**: masuk dengan NIP dan kata sandi. Beranda menampilkan ringkasan profil; "Profil saya" memuat data kepegawaian dari sistem kepegawaian. Data yang keliru diperbaiki di sumber (BKPSDM/SIASN), bukan di aplikasi ini.
- **Atasan langsung**: peran atasan muncul otomatis bila data jabatan mencatat Anda sebagai atasan. "Tim saya" berisi bawahan langsung yang aktif; bila bawahan pindah atasan, aksesnya berpindah pada sinkron berikutnya.
- **Koordinator OPD**: setelah ditugaskan pengelola untuk satu OPD, menu "Pegawai" menampilkan pegawai OPD tersebut saja.
- **Pengelola, CLO, administrator teknis, auditor**: wajib mengaktifkan verifikasi dua langkah (2FA) di menu "Akun" sebelum dapat membuka halaman lain. Siapkan aplikasi autentikator (TOTP) di ponsel.
- **Fasilitator, Dewan Pengarah**: pada fase ini hanya melihat profil sendiri; fitur peran menyusul pada fasenya.
- **Publik**: keaslian PDF terbitan diperiksa lewat kode QR → halaman `/verifikasi/…` (jenis, pemilik, tanggal, status, sidik digital; tanpa isi dokumen).
